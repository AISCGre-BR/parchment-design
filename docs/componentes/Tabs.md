# Tabs

Faixa de abas do espaço de trabalho: Texto, Fontes, Recortes, Tabela. Substitui o assistente Avançar/Voltar; todas as abas estão sempre acessíveis.

- Só o nome. Sem número, sem marcador de estado: a ordem da esquerda para a direita já diz a sequência do trabalho.
- Aba ativa: cantos superiores `radius-md`, fundo `workspace` que funde com o espaço de trabalho abaixo.
- Atalhos: Ctrl+1…4.
